# 面向日常使用的交付计划

本轮范围：Windows x64 便携交付 → 可跳过且能继续的首次引导 → 固定 Agent 验收入口 → 完整工作台迁移恢复。

- [x] 便携构建：内置 Python 与依赖、前端产物和必要资源；白名单打包，不带 data、密钥或开发缓存。验证独立启动、端口冲突、安全停止。
- [x] 首次引导：扫描、模型连接、选择对象询问；真实状态驱动，可跳过、可重新打开。
- [x] 固定验收：统一自动回归入口，覆盖配置检查、分类提案、冲突、额度耗尽、连接故障与恢复；区分协议模拟与真实模型质量评估。
- [x] 完整备份：包含数据库和配置原始备份，导出清单与校验摘要；恢复前验证包、保留原数据。跨电脑凭据重新配置，禁止自动执行旧任务。
- [x] 更新当前使用说明与构建/恢复说明，运行相关检查。

本轮不自动发布 GitHub Release、不替换用户现有数据、不修改真实被管理软件来验收。便携包在本地生成，可供下载和检查。

## 验收证据

- Windows 内置 Python 独立端口启动、安全停止、停止后导出/恢复/重启成功；运行中迁移被拒绝。使用便携副本，原工作台数据未替换。
- 4项迁移测试：完整往返与旧数据保留、篡改拒绝、路径穿越拒绝、目标不覆盖；原有5项维护脚本测试通过。
- 6项固定Agent场景通过（模拟提供方、真实运行器/临时存储），不作为真实模型质量评分。
- 核心浏览器回归通过；引导桌面/390px、跳过恢复、设置入口可用。
- ZIP约29 MiB，检查无data、node_modules、__pycache__；本机可用，尚未在独立干净Windows虚拟机验证。
- 新增GitHub Windows自动检查配置；远端执行结果以Actions为准，未自动发布Release。

内置 Python 3.13 下后端全量194项测试通过。
