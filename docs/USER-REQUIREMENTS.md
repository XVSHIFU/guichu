# 归处：用户要求与页面完善清单

整理日期：2026-10-06。依据本次开发对话；这是后续实现与验收的依据，不代表每项都已全面验收。

## 用户反复强调的要求

1. **通用发现，不做单机补丁。** 安装目录、程序入口、配置目录分别识别和展示；修复扫描源码，而不是只给某一个软件补字段。
2. **一个产品可有多个安装。** CLI、桌面应用、本地网页入口、npm/pip 工具都要覆盖；同名不同位置或不同形态不随意合并，重复登记则合并展示并保留证据。
3. **来源可解释。** 区分安装渠道、安装方式、下载来源；记录不足时保留未知，支持人工补充；官网链接不等于实际下载来源。
4. **列表要方便整理。** 磁盘直观展示，按扫描结果出现，最多展示十个；支持搜索、分类、多选和把多项交给助手，不仅限于单个对象。
5. **系统组件与附属程序默认隐藏。** 可主动显示；使用通俗名称“软件附属程序”。系统标记需有依据，不将所有微软软件或默认隐藏对象都判成不可删除。
6. **尽量使用软件自己的图标。** 应用包、程序资源、注册表、快捷方式可作为来源；无可用资源时使用默认图标。
7. **目录地图用于空间分析。** 参考 TreeSize；点击目录后保留矩形图并过渡到下层，末级目录可展开文件。小项聚合，避免标签堆满。文件排行按单文件排序，不混入“其他”聚合项。
8. **轻量文件操作。** 支持合适文件的默认应用打开、定位、复制路径，不发展成大型内置编辑器；执行文件不因点击就自动运行。
9. **助手尊重用户选择。** 自定义指令、上下文、多对象与工作方式可调整；风险提示要具体，避免反复劝阻。准确区分建议、工具支持、执行结果。
10. **过程可查看又不干扰阅读。** 参考 dsh/pi/Codex 的运行记录、文件读取与命令展示；步骤可折叠，助手侧栏可调整宽度，主导航可折叠。
11. **产品保持高效简洁。** 面向用户写文案；审查、实现细节留在文档。概览到详情渐进展示，减少重复分组、说明和空白，检查窄屏布局与多余焦点框。
12. **主题与交互连续。** 四分之一转盘在主题图标附近展开，有动画；滚轮选中即应用，切换有浸染效果；锁住背景滚动，Esc/点外部关闭；模式用图标、边角柔和、控件紧凑。
13. **借鉴已有实现。** 参考 myEnv 的发现位置、管理归属、命令入口及多环境分组；归处负责全机概览与解释，myEnv 的环境安装/切换能力可作为后续协作方向。
14. **验证真实结果。** 使用浏览器验收，不把工具返回、构建通过或一次模型成功等同于全部通过；保留限制和反例。提交推送遵循当前明确授权。

## 验收原则

- 隐藏和筛选只影响展示，不删除真实软件、配置或记录。
- 不将识别规则、风险建议自动升级为执行权限；也不将风险标记当成禁止讨论的理由。
- 多选进入助手只附带上下文，不自动发起请求或修改。
- 后续事项未实施前不得在汇报中写成完成；历史实现仍以对应测试与验收记录为准。

## 搜索、目录与记录布局补充（2026-10-06）

- 搜索输入的焦点提示放在外层容器，避免输入文字周围重复方框；保留键盘可见焦点。
- 目录统计区分未统计与真实空目录。达到预算后不把待扫描目录显示为零大小，不依据缺失子树判断末级目录。
- 未完整统计的末端条目可展开当前层的文件夹和文件。旧统计不自动伪造补全；重新统计采用逐层扫描，并保存子树完整性。
- 变化记录分为对象变化、检查记录、操作记录。检查详情折叠，最近十条起步，按需显示更多；取消无关的环境速览栏。
- 验证：目录统计 9 项测试通过；构建通过；浏览器确认搜索外层焦点、检查记录折叠和真实 Users 目录展开。旧 C 盘统计仍受原有条目限制，未宣称全盘统计完成。

## 深入统计与读取原因（2026-10-06）

- 对整盘/大目录提供深入统计：最多 30 分钟、500 万条目，保留停止操作。默认普通统计的预算不变。
- 错误分类保存为权限不足、扫描中消失、其他读取错误；链接/特殊文件跳过与硬链接去重单独说明，可展开前 100 项路径。
- 不为了减少错误计数修改系统 ACL 或把失败当成功；旧记录无路径原因时明确提示重新统计。
- 10 项目录统计测试和前端构建通过。真实 C 盘深入扫描突破原 20 万项上限；实际覆盖结果以本机任务记录为准。

## 目录下钻与按需提权（2026-10-06）

- 缓存目录树缺失子节点时，先实际枚举判断是否含子目录。有子目录则在当前矩形图中补充统计并下钻，保留上一级；无子目录且无读取错误时才展开文件。
- 补充统计显示进度并支持停止；已知子目录在补充期间仍能浏览。
- 管理员选项默认关闭，启动时由 Windows UAC 授权，仅启动独立扫描进程；普通工作台负责保存结果，扫描进程不打开数据库，不修改目录权限。
- 真实浏览器确认 AppData 下钻后显示 Local、Roaming、LocalLow。普通统计 10 项、提权协议与授权取消 3 项测试通过，构建通过。真实 UAC 接受及管理员完整扫描尚未人工验收。
