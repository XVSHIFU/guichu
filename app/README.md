# 归处 · Local Desk

运行根目录的「启动工作台.cmd」，访问 http://127.0.0.1:8765 。关闭网页不会停止本地服务；不设置开机自启。旧版静态清单及采集脚本保存在 `../local-archive/`，不进入仓库。

## 当前能做什么

- 扫描 Windows 软件注册表、已知 Agent 入口、当前用户点目录、本地 Skill / 插件 / MCP 配置。
- 全局搜索（Ctrl K）、分类筛选、对象详情和双向关联、复制路径、打开文件所在目录。
- 兼容 OpenAI 的只读助手、会话历史、对象摘要工具与可取消运行（真实模型仍需自行配置验证）。
- Codex 独立 MCP 配置启停的预览、确认、备份、恢复和冲突记录。
- 按需目录大小统计、人工软件分类纠错。
- 登记便携软件目录与项目配置来源，维护人工关联，查看持久扫描记录。
- 目录回收与 MSI 官方卸载入口：先预览、再确认，在变化记录中核对结果。
- 保存保留意向及备注；重新检查不覆盖。未保存的草稿在当前浏览器会话保留。
- 查看磁盘容量、CPU/内存抽样、前后检查的对象变化。
- 浅深色、手机宽度布局、键盘操作、离线最近快照。

## 边界

这是本机环境目录的第一版，不是完整软件卸载器。扫描不执行安装、卸载、自动删除，不执行技能正文或连接 MCP。已发现、配置启用、入口找到和实际可用是不同状态。关联依据已知位置与配置，不证明每次会话实际调用。

不覆盖 WSL、所有项目级配置和云端账号插件。目录占用只在点击后按需递归统计；磁盘容量是真实值，不把历史目录大小当现值。扫描错误会报告，部分扫描失败时不推断对象被移除。没有后台文件监听，变更通过「刷新检查」发现。未知工具可能只出现在软件清单或目录中。

备注与最近 20 次快照保存于 `data/workbench.sqlite3`，页面离线快照保存于浏览器本地存储。配置正文、环境变量和模型 API 密钥不发送到页面；本地描述和路径仍属于个人数据，请勿直接分享数据库。服务仅监听 127.0.0.1，写操作校验 Origin 和随机令牌；配置写入仅接受清单对象 ID，目录浏览和大小统计另有本机路径校验。

## 第二轮：真实只读助手

在设置的“模型连接”填写兼容 OpenAI 的基础地址、模型名称与密钥，保存后测试连接。测试只发送通用问题。密钥通过 Windows DPAPI 加密保存在 `data/model-provider.json`，页面不回显；更换服务地址需重新填写密钥。运行任务期间不能更换连接。

助手直接使用已配置模型，点击发送即提交请求及当前上下文；发送范围说明可在会话详情的对象页查看。所选对象及直接关联固定为本次任务范围；未选择对象时可查询清单。工具只提供扫描元数据、关系、配置摘要和已收录目录的当前层名称，不读取配置正文、不执行命令。请求与本会话只读历史也发送到所配服务。

运行支持逐步回答、工具事件、取消、用量与请求/工具/时长限制；会话、任务、事件存 SQLite。服务重启将未完成任务标记中断，不自动重放。模型的工具要求不能扩大授权范围。删除会话同时移除其运行记录；活动任务须先结束。

本轮先用模拟提供方与本机 SSE 服务验证协议、取消和持久化；用户实际端点/模型仍待配置并实测。`OpenAI 兼容`不代表所有提供方对流式、工具、usage 与 token 参数均兼容。P3 的独立 Codex MCP 启停动作现已接入详情；助手本身仍只有只读工具。


## 保留标记的提案与恢复

对象详情的“操作”页可生成保留决定提案，展示执行前后差异；确认才更新工作台数据库。操作历史保留在 SQLite，执行后可恢复原备注与决定；若备注已被后续编辑，执行或恢复会停止并提示冲突。此功能不修改软件配置或电脑文件。原“备注”页仍可直接编辑备注。


## Codex MCP 配置动作

在“技能与连接”选择 Codex 用户配置中的独立 MCP，打开详情“操作”：选择启用或停用、生成提案、检查 enabled 差异与固定路径和备份位置，再确认修改。仅支持已有简单名称独立 `[mcp_servers.name]` 表；插件 MCP、项目配置和复杂 TOML 写法暂不支持。用户层修改可能被其他层覆盖，已运行的宿主也可能需要重启，不能把写入成功当作连接已切换。

提案绑定配置全文 SHA-256 与版本；写前重新核对。备份原字节至 `data/config-backups`，备份文件仅当前用户与 SYSTEM 可访问；保存恢复记录后才替换配置。原目标 DACL 被保留，写后回读校验。历史中可恢复，配置有后续改动时拒绝覆盖。进程锁及摘要检查不能完全排除其他编辑器在最终替换瞬间的竞争，请勿同时编辑该配置。

服务中断不自动重放。历史显示中断及当前文件与前后摘要的匹配状态；有备份记录且当前等于执行后摘要时可恢复。记录与备份一起保留，不要只删除其中一个。

验证使用临时 HOME/SQLite/TOML 的真实 HTTP 闭环及 Windows 权限测试；没有为验收修改用户真实 Codex 配置。


## 目录大小与软件分类

目录地图进入具体目录后点击“统计目录大小”。任务在后台运行，可停止、返回后查看；逻辑文件长度不是实际磁盘分配空间。硬链接去重，不跟随链接；存在读取错误、跳过项、120秒或20万条目限制时显示部分结果。完成只表示遍历时观察到的结果，并非文件系统原子快照。

软件详情“备注”中可选择人工分类，也可恢复自动识别。分类保存本机数据库，重新检查保留；规则识别与人工决定分开保存。


## 启动、停止与数据库备份

根目录“启动工作台.cmd”启动并打开页面；“停止工作台.cmd”安全停止。停止会核对进程身份，并在分析、统计、扫描或配置修改期间拒绝；不按端口强杀进程。也可运行 `Start-Workbench.ps1 -NoBrowser`，脚本支持指定 `-Port`。

“备份工作台.cmd”使用 SQLite 在线备份生成 `app/data/backups/*.sqlite3`。恢复前先停止服务，再运行 `app/Restore-Workbench.ps1 -BackupPath <该工作区备份绝对路径>`；恢复会检查完整性并另存当前数据库。备份脚本只备份数据库，不包含模型密钥文件、图标或配置原字节备份；搬迁完整工作台时另行保留 data/config-backups，否则历史中的配置恢复入口会缺少备份。

日志在 `app/data/server.log` 和 `server-error.log`，进程记录在 `server-process.json`。已有服务若非本脚本启动且无可信记录，脚本会拒绝认领或强停。


## 检查历史与人工关联

变化记录页显示最近20次检查任务。成功、部分成功、失败及服务重启中断分别记录；失败不会自动重试。任务记录与对象变化分开：一次成功检查可以没有对象变化。

详情“关联”页可搜索另一个已收录对象并添加说明。人工关联和扫描发现分开保存，移除人工记录不影响扫描关系；已不存在的端点会标记未收录，不自动转绑其他对象。助手查询关系时也区分人工记录与扫描发现。


## 登记便携软件与项目来源

设置 → 补充检查来源：选择便携软件或项目配置，填写本机绝对目录，登记后点击重新检查。不会自动登记真实路径；最多20个来源，拒绝磁盘根、网络目录与链接路径。移除只取消登记，下次检查移除该来源对象，不删除文件。

便携来源只看根及一级子目录的 EXE 元数据，不执行程序；最多500个条目、100个入口，超限显示部分检查。图标沿用本机资源提取流程。一个入口记录不等于一个独立安装软件。

项目来源只读取根下 `.codex/config.toml` 与 `.mcp.json` 的 MCP 白名单元数据；单文件2MB、每来源200项，密钥/env/args不进入清单。项目来源仅标记配置发现，不判断信任、覆盖优先级或当前是否实际加载；不开放项目配置修改。各来源失败独立保留旧证据。

## 受限清理入口

对象详情 → 操作 → 预览范围 → 勾选确认 → 执行；变化记录保留历史快照。

- 目录使用 Windows 专用回收接口，依赖 pywin32。拒绝保护路径、链接、非固定盘与超限目录；进程检查不是全量句柄检查，请先关闭相关程序。恢复通过 Windows 回收站手动完成。
- 软件仅支持可核验的 MSI 注册记录；启动官方交互卸载后，需要核验注册状态。其他安装器暂不支持，不执行注册表中的任意卸载命令。
- 重启中断不会自动重试；失败时检查原目录、回收站或官方窗口。模型助手仍是只读，没有清理执行工具。

验证：118项后端测试通过，清理界面mock测试通过；实际回收仅测试新建临时目录，真实软件未卸载。真实模型仍待本机配置验收。

## 对话与操作来源

从助手的“预览并确认对象操作”进入操作页，新提案保存服务端核验过的来源会话；已完成的对应运行也可被引用。来源不代替用户确认。删除对话不会删除已生成的操作记录与来源快照。

会话中的关联操作记录汇集保留决定、MCP配置和清理结果。配置历史在“变化记录”中独立保留，恢复仍需检查当前配置与执行备份是否匹配。

助手历史可恢复成功/失败/取消任务的状态、错误、用量和工具事件；点击消息旁“查看运行记录”回看旧运行，支持返回最新。长事件记录按游标完整续读。来源互链及运行历史均通过模拟浏览器验证，真实模型仍待用户配置验收。

## 模型提供商与模型目录

## Agent 首版（2026-10-03）

本节替代前文“助手仍只读”“另行进入操作页”的阶段说明。助手可以按需加载6项内置技能，查询对象、关联、实时受支持配置和有预算的目录大小，并在聊天生成保留决定或Codex MCP启停/恢复提案。配置实际执行仍由用户卡片确认，服务端校验与备份后执行；模型本身没有任意shell或批准工具。

- 模型连接的「调用预算与超时」可一键使用推荐额度：16次工具、6轮模型、120秒、4096输出token。既有设置保留；工具0–32次、请求1–12轮与实际运行一致。
- 较早会话自动整理为持久化语义摘要，保留目标、决定、待办与依据；整理计入请求预算，失败有最近消息回退。
- 可在聊天批量调整软件分类（最多50项），预览后整批确认，支持冲突检测与恢复。
- 配置适配支持Codex用户MCP启停，以及Claude Code用户MCP注册移除/原始备份恢复；不修改项目级Claude配置。
- 设置→助手→添加连接支持本机stdio与远程Streamable HTTP，远程使用HTTPS或回环HTTP，可选Bearer令牌，本机DPAPI加密保存。先发现工具、逐项允许，再启用；目前不提供OAuth登录。

所有实际修改仍需点击提案卡确认。查询缓存只用于当前任务内的静态清单，实时配置检查不会复用旧读取。
